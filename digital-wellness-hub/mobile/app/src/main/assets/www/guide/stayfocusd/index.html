Guide 02 / Chrome extension

Put one site behind a small limit.

Try a modest daily website allowance first. Read the permissions and strict-mode warning before you install or start a block.

Before you begin

Know what the extension can access.

The Chrome Web Store listing says the extension requests permission to read and change data on websites you visit. Review the current permission prompt and privacy details yourself before continuing.

Set up a simple limit

  1. Open the official Chrome Web Store listing.Check the publisher name and current version. This guide is for Chrome; browser availability can change.
  2. Review the permissions and privacy details.Continue only if the access requested makes sense to you. If it does not, close the listing and do not install.
  3. Install only from the official listing.Use the store’s install button, then open the extension from Chrome’s Extensions menu.
  4. Choose one site and a modest time allowance.In Blocking Settings, find the group’s blocked-site list and Max Time Allowed per Day. Add one test site, choose a small allowance, then save the changes. Labels may vary by version.
  5. Review your settings before the limit starts.Check which sites and hours are covered, then test only with a non-sensitive site.
Important: Avoid StayFocusd’s Nuclear Option for a first test. The current Chrome Web Store listing says an active Nuclear Option block cannot be canceled. The listing also describes a Require Challenge setting that can make changing settings harder.

If something feels wrong

  • Before a block starts, review the site list and allowance in Blocking Settings. Make any changes while the extension allows them.
  • Do not assume an active block can be paused, canceled, or bypassed; those controls may not be available.
  • Before starting any strict block, read the current listing and in-product warning, and choose a duration you can safely wait out.
  • If a strict block is already active, use the extension’s official help channel. This guide does not promise an undo method.

We have not installed or tested this extension on a student device. The steps describe the current official listing, not a verified device walkthrough.

Before you start

  • Chrome on a compatible device
  • A non-sensitive test website
  • Time to review permissions
