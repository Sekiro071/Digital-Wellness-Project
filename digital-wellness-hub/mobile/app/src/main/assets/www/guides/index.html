Make the setting real

Three small changes, step by step.

Short, student-written walkthroughs for common devices and browsers. Versions change, so each guide links you back to the current official help page.

Before you begin

A good guide respects your context.

Use the steps as a starting point, not a promise that every screen will look identical on every device.

01 / CHECK

Confirm the platform.

Device menus differ. The guide tells you which platform it was written for and where variation is likely.

02 / REVIEW

Read permissions.

Especially for browser extensions, check the publisher, permissions, and official store listing before installing.

03 / TEST

Try a safe example.

Use a non-sensitive website or a small time limit first. Make sure you know how to change or undo the setting.
